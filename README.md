# GrammarCorrect

A fast, lightweight, and modern web application for grammar checking, text editing, and AI-powered document summarization. Built with React, Tailwind CSS, and powered by Google Gemini and Gemma models.

## Features

- 📝 **Real-Time Grammar & Style Correction**: Highlights spelling errors, grammatical mistakes, and stylistic improvements directly in the editor.
- 🎯 **Click-to-Navigate**: Click on any suggestion card in the sidebar to automatically scroll to and highlight the exact text position in your document.
- ⚡ **Correct All**: Fix all issues instantly with a single click.
- 📊 **Dynamic Score Rating**: Overall text quality score dynamically recalculates in real-time as you accept or dismiss corrections.
- 📋 **Executive Summary Tab**: Get high-level takeaways, key points, tone analysis, and estimated reading time.
- 💾 **OPFS Local Storage**: Uses Origin Private File System (OPFS) with LocalStorage fallback to automatically save drafts locally.
- 🤖 **Multiple Model Support**: Switch seamlessly between Google Gemini (3.7 Flash, 3.5 Flash, 3.1 Pro) and Google Gemma models.
- 🌙 **Dark Mode**: Fully supports light and dark themes.
- 📱 **Responsive Design**: Clean, modern interface designed for both mobile and desktop screens.

## Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/GrammarCorrect.git
   cd GrammarCorrect
   ```

2. **Run locally:**
   Simply open `index.html` (or `ai_grammar_checker.html`) in any modern web browser. No complex build step or server setup required!

3. **API Key Setup:**
   Provide your Google Gemini API key in the top settings bar to start analyzing text with AI.

## Built With

- **HTML5 & CSS3** (2-space indentation standard)
- **Tailwind CSS** (via CDN for fast styling)
- **React 18** & **Babel** (In-browser JSX transformation)
- **Google Gemini API**
